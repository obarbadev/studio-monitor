Prévia MIT do Studio Monitor, um aplicativo Electron local para acompanhar projetos e equipes de agentes.

### Downloads

- Windows x64: instalador `.exe` ou arquivo `.zip`.
- macOS Apple Silicon: `.dmg` ou `.zip` com `arm64` no nome.
- macOS Intel: `.dmg` ou `.zip` com `x64` no nome.
- Código-fonte: arquivos `source.zip` e `source.tar.gz`.
- `SHA256SUMS.txt`: hashes SHA-256 para conferir os downloads.

### Incluído

Canvas de agentes, chat com Markdown e slash commands, atividade em tempo real, inspeção de instruções e skills, templates de jogos e fábrica de software, monitoramento de uso Claude e fallback Claude → Codex → Antigravity (AGY). Projetos e logins permanecem na máquina.

### Antes de usar

Instale e autentique pelo menos um dos programas oficiais: Claude Code, Codex ou AGY. No Windows, utilize os executáveis nativos `.exe`. Templates com scripts também precisam de Git Bash e Python 3 disponível como `python3`. O instalador do Studio não instala esses programas nem inclui contas ou credenciais.

Esta é uma versão de teste **sem assinatura digital de publicador e sem notarização Apple**. Windows e macOS podem mostrar alertas ou impedir a abertura pelos controles padrão. A aplicação usa os modos sem confirmações solicitados: Claude bypass permissions, Codex dangerously-bypass-approvals-and-sandbox e AGY dangerously-skip-permissions. Use-a apenas com projetos e instruções em que confia.

O login assistido por Terminal está integrado no macOS; no Windows, faça o login no programa oficial pelo terminal e clique em Verificar conexões. Sessões externas são descobertas para Claude; Codex e AGY retomam as conversas iniciadas pelo Studio. O Studio não inventa saldo ou data de reset quando o provedor não os informa.

Os testes automatizados usam execução simulada de modelos; a publicação dos pacotes não comprova execução real com todas as contas ou provedores no Windows e no macOS Intel. O template Donchitos mantém sua atribuição e licença MIT. Veja LICENSE, THIRD_PARTY_NOTICES.md e docs/distribution.md no código-fonte.

### Origem dos pacotes desta versão

Builds feitos localmente no macOS após bloqueio de cobrança impedir o início dos runners GitHub Actions. Windows x64 foi gerado por cross-build, com ícone e metadados do aplicativo, sem assinatura; não foi executado em Windows. macOS Intel foi gerado para x64; a validação interativa local ocorreu em Apple Silicon. O código e o aplicativo usam licença MIT.

### Identidade visual

Ícone próprio do Studio Monitor em preto e branco, aplicado à interface, ao Dock, ao aplicativo Windows e aos instaladores. PNG, ICO e ICNS estão incluídos no código-fonte.
