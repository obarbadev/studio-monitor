# Fontes do anúncio comparativo

Consultadas em 3 de novembro de 2026. A thread compara propostas documentadas; não é um benchmark e não afirma que os recursos do Studio sejam exclusivos.

- OpenBot: agentes persistentes e workspace próprio — https://openbot.run/
- Grok Bot: computador persistente na nuvem e execução com o cliente fechado — https://docs.x.ai/grok-bot/overview
- Maestri: canvas espacial com terminais, notas e arquivos — https://www.themaestri.app/en/docs/intro
- OpenMausBot: bots com uso de computador, incluindo desktop remoto e VM local — https://github.com/milind-soni/OpenMausBot

Recursos do Studio conferidos no código e na release v0.1.3. O Studio usa os CLIs locais; chamadas de modelo continuam dependentes dos provedores. O fallback entre provedores transfere contexto parcial para uma sessão própria do destino.
