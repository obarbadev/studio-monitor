# Coordenação

Um briefing de delegação contém objetivo, arquivos autorizados, contexto mínimo,
critério de aceitação, verificações e formato de retorno. O dono da tarefa mantém o
registro da história. Não use simultaneamente dois agentes para alterar os mesmos arquivos.
Quando paralelo, delimite arquivos ou use worktrees já autorizados e revise a integração.

Fluxo lógico: produto → arquitetura → implementação → qualidade → entrega.
É uma organização de responsabilidades, não uma exigência de chamar todo o time.
O principal coordena ferramentas, aprovações, dependências e comunicação com o usuário.

Conflitos de requisito vão ao produto; decisões estruturais à tecnologia; conflitos
entre qualidade, prazo e escopo são apresentados com impactos concretos para o usuário.
Cada retorno deve separar fatos observados, hipóteses, alterações e evidências.
Preserve alterações do usuário. Não use reset, clean ou checkout para apagar trabalho alheio.
